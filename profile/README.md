## 💳 Payment Hub

**Payment infrastructure for event platforms.**

Payment Hub acts as an intermediate layer between event platforms and payment gateways, providing a centralized way to manage payment transactions and payment-related information.

### Key capabilities

- Payment gateway integration
- Transaction management
- Payment status tracking
- Success and failure handling
- Gateway response management
- Centralized payment data
- Event-specific payment workflows

---

## ⚙️ CMS Workflow

**A centralized content and workflow platform for event websites.**

CMS Workflow powers dynamic event websites by providing APIs and backend workflows for managing event content and operations.

### Manage

- Event information
- Speakers
- Sponsors
- Sessions
- Venues
- Galleries
- Abstracts
- Registrations
- Contact submissions
- Event pages
- Dynamic website content

One backend can power multiple event websites while keeping content and workflows centralized.

---

## 🤖 PulseDesk

**AI-powered communication for event websites.**

PulseDesk helps event organizers provide instant assistance to attendees and website visitors through intelligent conversational experiences.

It can help answer common event questions, guide visitors through event information, and provide a more interactive experience.

### Designed for

- Attendee support
- Event FAQs
- Registration assistance
- Venue and schedule information
- Event navigation
- Automated communication
- AI-powered assistance
